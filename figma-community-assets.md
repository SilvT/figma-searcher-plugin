━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Find every layer using a specific variable, style, or effect — before you rename or delete it.

Figma has no built-in way to search token usage across a file. This plugin closes that gap.

▸ SEARCH
◆ Search by variable, style, or effect name
◆ Partial matches — search "background" and find every match: core/background, brand/background, input-field/active/background
◆ Type names with / or . — both work
◆ Search one name at a time, or paste a list to search many at once
◆ Scope: current page (fast) or the whole file (thorough)

▸ RESULTS
◆ Grouped by page and component
◆ "Ignore nesting" — hide layers that only inherit a match from a parent, keep the direct hits
◆ Click a result → selects and zooms to that layer
◆ Export as CSV or JSON, auto-named after your search query

▸ GOOD FOR
✓ Checking what breaks before renaming or deleting a token
✓ Auditing where an old or deprecated style is still used
✓ Sanity-checking a design system rollout

▸ WHAT IT DOESN'T DO
✕ Search across multiple files at once
✕ Search inside library components you haven't inserted into the file
✕ Rename or edit anything — read-only, always

▸ PRIVACY & ACCESS
✓ No login, no account, no PAT required
✓ No network access — nothing leaves your file
✓ Works in Design mode and Dev mode
✓ Works on any design file

## SEO / searchability notes
- Figma Community search weighs the **plugin name** most heavily, then tagline/description, then tags. "Variable, Style & Effect Finder" was chosen specifically to match all three literal search terms.
- Tagline is capped at 100 characters and is the first thing shown on the listing card — front-load the actual function, not a slogan.
- Put the highest-value sentence in the *first two lines* of the description — Figma truncates with "Read more," so anything after that is only seen by people who already clicked in.
- Use plain glyphs (→ • ✓) instead of colored emoji for scanability without looking unpolished.
